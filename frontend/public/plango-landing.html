HOW IT WORKS
3단계로
바로 시작
1
계좌 연동
키움증권 API를 PlanGo 백엔드에 연결합니다. 인증키 입력 한 번으로 모든 종목 데이터가 자동 수집됩니다.
2
매매 전략 설정
종목별로 분할매매 또는 무한매매를 선택하고 조건을 설정합니다. 분할과 무한 전략을 서로 다른 종목에서 동시에 진행할 수 있습니다.
3
자동 실행·모니터링
대시보드에서 실시간 상태를 확인하고 설정한 조건에 따라 분할매매 또는 무한매매가 자동으로 매매가 시작됩니다. WebSocket으로 현재가와 주문·체결 상태를 실시간으로 확인합니다.

FAQ
자주 묻는 질문
어떤 증권사를 지원하나요?
PlanGo 프로그램은 키움증권의 RestAPI에서 구동됩니다. KRX(한국거래소)와 (넥스트레이드) 양 거래소 모두 실시간 데이터를 제공합니다.
PC가 꺼져 있어도 자동매매가 돌아가나요?
PlanGo 백엔드를 서버에 배포하면 24시간 365일 PC 없이 자동매매가 가능합니다.
Trailing Stop 갱신 주기를 바꿀 수 있나요?
WebSocket을 통해 실시간으로 가격과 상태를 전달받습니다. 거래시간 외에는 실시간 데이터 연결이 필요하지 않은 경우 자동으로 관리됩니다.
내 계좌 정보는 안전한가요?
모든 계좌 정보와 API 키는 오직 사용자 본인의 서버에만 저장됩니다. PlanGo는 어떠한 매매 내역이나 잔고 정보도 수집하지 않습니다.
코딩을 몰라도 사용할 수 있나요?
프로그램 기능개선 및 수정은 원격으로 서비스 예정입니다. 초기설치시 방분 1:1 지원을 통해 도움을 드리고 HW적인 문제에 대해서는 보증기간내 서비스를 제공합니다.
매매 손실에 대한 책임은 누가 지나요?
종목선택 및 주문조건 실행 판단은 사용자 본인이 하며, 투자 결과에 대한 책임은 전적으로 투자자 본인에게 있습니다. PlanGo는 사용자가 설정한 조건에 따라 주문 실행을 지원하는 도구이며 투자를 권유하지 않습니다.
